# Leytech Portfolio

Open `index.html` in a browser or use Live Server in VS Code.

## Customize before publishing
1. Replace placeholder contact details in `index.html`.
2. Replace the visual project placeholders with your real project screenshots/images.
3. Add your real GitHub, LinkedIn, Instagram and WhatsApp links.
4. Add your real CV file/link.
5. Connect the contact form to Formspree, EmailJS, a backend, or another form service.

Files:
- index.html
- style.css
- script.js
